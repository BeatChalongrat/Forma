# Process flow · 1.1.0
Use save_flow to create or revise an editable process. Separate observed runtime events from a proposed process. Ask when a branch or responsibility is unknown. Name steps with clear verbs and label branches. For a formal SOP export, load this skill and use create_document with process template, flow_artifact_id and the exact flow_version. The server copies that version and checks ownership. The diagram is a user/assistant-authored process, not evidence that these events actually happened. The source register must say so. Never hide edges or disconnected nodes to make the diagram fit; split pages or ask to simplify.
