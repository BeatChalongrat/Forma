# Q10 มีแต่หัวตาราง ไม่มีข้อมูล

**สถานการณ์:** export ตอนยังไม่มีสินค้าในเงื่อนไข

**ลูกค้า:** `MTQ10`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

สร้างลูกค้าตามรหัสของเคส (เช่น `MTQ01`) แล้วอัปโหลดเหมือนกลุ่ม L ดูว่าระบบเตือนตรงตามเคสหรือไม่

## ผลที่ควรได้

- ระบบระงับ เพราะไม่มีข้อมูลสักแถว
- ไม่มี JSON ออกมา

ค่าที่ควรเห็นในระบบ:

- สถานะรอบ: `blocked`
- การตัดสินของ policy: `block`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา
