# A10 Excel ที่ไม่มีข้อมูลเลย

**สถานการณ์:** export ออกมาแต่ไม่มีแถวใดเลย

**ลูกค้า:** `MTFILE`

**ไฟล์:**
- `ว่าง.xlsx`

## วิธีทำ

สร้างลูกค้า `MTFILE` ครั้งเดียว แล้วใช้กับทุกเคสในกลุ่มนี้ ไปที่ อัปโหลดไฟล์ > รวมไฟล์ของลูกค้า เลือก `MTFILE` แล้วอัปโหลดไฟล์ของเคส

## ผลที่ควรได้

- ไม่มีตารางให้จับคู่ ระบบต้องบอกว่าไม่มีข้อมูล
- ไม่มี JSON ออกมา

ค่าที่ควรเห็นในระบบ:

- ตอนอัปโหลด: `accepted`
- สถานะรอบ: `failed`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา
