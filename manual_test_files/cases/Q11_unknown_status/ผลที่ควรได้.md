# Q11 สถานะที่ระบบไม่รู้จัก

**สถานการณ์:** ลูกค้าใช้คำว่า 'พักการขาย', 'รอของ'

**ลูกค้า:** `MTQ11`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

สร้างลูกค้าตามรหัสของเคส (เช่น `MTQ01`) แล้วอัปโหลดเหมือนกลุ่ม L ดูว่าระบบเตือนตรงตามเคสหรือไม่

## ผลที่ควรได้

- ค่าที่ไม่รู้จักต้องไม่ถูกแปลงเป็น active เงียบ ๆ
- สองรายการนั้นผิดสัญญา JSON (สถานะไม่อยู่ในรายการที่กำหนด) ต้องแก้ก่อนส่งออก

ค่าที่ควรเห็นในระบบ:

- สถานะรอบ: `review`
- รายการผิดสัญญา JSON: `2`
- ข้อสรุปขั้นข้อมูล: `contract_broken`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา
