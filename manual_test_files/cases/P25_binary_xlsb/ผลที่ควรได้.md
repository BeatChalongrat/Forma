# P25 ไฟล์ Excel แบบ .xlsb

**สถานการณ์:** ไฟล์ใหญ่มักถูกบันทึกเป็น Excel Binary Workbook

**ลูกค้า:** `MTP25`

**ไฟล์:**
- `สินค้า.xlsb`

## วิธีทำ

สร้างลูกค้าตามรหัสของเคส (เช่น `MTP01`) แล้วอัปโหลดเหมือนกลุ่ม L

## ผลที่ควรได้

- หน้าอัปโหลดรับไฟล์นี้
- อ่านได้ แต่ระบบต้องให้คนตรวจทุกรอบ เช่นเดียวกับ .xls
- ได้ 12 รายการ

ค่าที่ควรเห็นในระบบ:

- สถานะรอบ: `review`
- จำนวนรายการ: `12`
- รายการผิดสัญญา JSON: `0`

## JSON

เทียบไฟล์ที่ดาวน์โหลดกับ `expected.json` โดยไม่ต้องเทียบ `source_meta`
