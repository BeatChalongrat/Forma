# Q03 บางแถวไม่มีรหัสสินค้า

**สถานการณ์:** สินค้าใหม่ที่ยังไม่ได้ตั้งรหัส

**ลูกค้า:** `MTQ03`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

สร้างลูกค้าตามรหัสของเคส (เช่น `MTQ01`) แล้วอัปโหลดเหมือนกลุ่ม L ดูว่าระบบเตือนตรงตามเคสหรือไม่

## ผลที่ควรได้

- ต้องบอกว่ามีแถวไม่มีรหัส พร้อมจำนวน
- แถวเหล่านั้นต้องไม่หายเงียบ ๆ

ค่าที่ควรเห็นในระบบ:

- สถานะรอบ: `review`
- ต้องมีคำเตือนเรื่อง: `identity`
