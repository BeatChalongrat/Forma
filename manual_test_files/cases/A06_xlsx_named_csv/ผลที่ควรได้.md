# A06 ไฟล์ Excel ที่ตั้งชื่อเป็น .csv

**สถานการณ์:** เปลี่ยนนามสกุลผิดอีกทาง

**ลูกค้า:** `MTFILE`

**ไฟล์:**
- `export.csv`

## วิธีทำ

สร้างลูกค้า `MTFILE` ครั้งเดียว แล้วใช้กับทุกเคสในกลุ่มนี้ ไปที่ อัปโหลดไฟล์ > รวมไฟล์ของลูกค้า เลือก `MTFILE` แล้วอัปโหลดไฟล์ของเคส

## ผลที่ควรได้

- ถูกปฏิเสธ และบอกว่าเป็นไฟล์ workbook
- ไม่มีรอบที่ค้างเงียบ ๆ และไม่มีข้อมูลว่างเปล่าเข้าระบบ

ค่าที่ควรเห็นในระบบ:

- ตอนอัปโหลด: `rejected`
- ข้อความต้องมีคำว่า: `not a CSV`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา
