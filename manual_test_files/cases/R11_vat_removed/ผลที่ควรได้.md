# R11 ราคาลด 7% ทุกตัว แต่หัวคอลัมน์ยังบอกว่ารวม VAT

**สถานการณ์:** ลูกค้าเปลี่ยนไป export ราคาก่อน VAT โดยไม่แก้หัวคอลัมน์

**ลูกค้า:** `MTEXP`
**ต้องทำก่อน:** `R00`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

ทำ `R00` ให้จบก่อน จนดาวน์โหลด JSON ได้ จากนั้นอัปโหลดแต่ละเคสให้ลูกค้า `MTEXP` ทีละเคส ดูผลแล้วเปิดเมนูของรอบ เลือก ยกเลิกรอบ โดยไม่ต้องกดยอมรับ เว้นแต่เคสบอกให้ทำ รอบที่ยกเลิกจะไม่กระทบเคสถัดไป

## ผลที่ควรได้

- ระบบจับได้ว่าราคาลดลง 7% เท่ากันทุกรายการ
- มีคำถามเดียว: ราคานี้ไม่รวม VAT แล้วใช่ไหม

ค่าที่ควรเห็นในระบบ:

- การตัดสินของ policy: `review`
- ข้อสรุป: `vat_shift`
