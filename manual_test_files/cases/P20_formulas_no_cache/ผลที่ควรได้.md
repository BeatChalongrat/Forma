# P20 ราคาเป็นสูตรที่ยังไม่เคยคำนวณ

**สถานการณ์:** ไฟล์ถูกสร้างจากโปรแกรม ไม่เคยเปิดใน Excel จึงไม่มีผลลัพธ์ของสูตร

**ลูกค้า:** `MTP20`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

อัปโหลด แล้วดูว่ารอบล้มเหลว หรือถูกส่งให้คนตรวจพร้อมเหตุผลเรื่องสูตร

## ผลที่ควรได้

- ระบบต้องไม่เห็นเป็นราคาว่าง
- ต้องปฏิเสธ และบอกให้เปิดบันทึกใน Excel ก่อน
- ไม่มี JSON ออกมา

ค่าที่ควรเห็นในระบบ:

- สถานะรอบ: `failed`
- ข้อความต้องมีคำว่า: `formula`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา
