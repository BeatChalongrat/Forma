# S02 รูปแบบ JSON ที่ใช้ oneOf

**สถานการณ์:** สัญญา JSON ใช้ความสามารถที่ระบบไม่รองรับ


**ไฟล์:**
- `unsupported.schema.json`

## วิธีทำ

ไปที่ ตั้งค่า > Target formats แล้วเพิ่ม unsupported.schema.json

## ผลที่ควรได้

- ถูกปฏิเสธตั้งแต่ลงทะเบียน พร้อมบอกว่าไม่รองรับตรงไหน

ค่าที่ควรเห็นในระบบ:

- ตอนลงทะเบียน: `rejected`
- ข้อความต้องมีคำว่า: `does not support`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา
