# S03 ไฟล์ JSON พัง

**สถานการณ์:** วางข้อความที่ไม่ใช่ JSON


**ไฟล์:**
- `broken.schema.json`

## วิธีทำ

ไปที่ ตั้งค่า > Target formats แล้ววางเนื้อไฟล์ broken.schema.json

## ผลที่ควรได้

- ถูกปฏิเสธ และไม่มีรูปแบบค้างในระบบ

ค่าที่ควรเห็นในระบบ:

- ตอนลงทะเบียน: `rejected`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา
