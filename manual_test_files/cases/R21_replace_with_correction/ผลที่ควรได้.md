# R21 ลูกค้าส่งไฟล์แก้มาแทนรอบเดิม

**สถานการณ์:** รอบแรกราคาผิด แล้วลูกค้าส่งไฟล์แก้ตามมา

**ลูกค้า:** `MTEXP`
**ต้องทำก่อน:** `R00`

**ไฟล์:**
- `1_ไฟล์ราคาผิด.xlsx`
- `2_ไฟล์แก้แล้ว.xlsx`

## วิธีทำ

อัปโหลด 1_ไฟล์ราคาผิด.xlsx ให้ MTEXP จากนั้นเปิดเมนูของรอบ เลือก แทนที่ด้วยไฟล์ใหม่ แล้วเลือก 2_ไฟล์แก้แล้ว.xlsx

## ผลที่ควรได้

- รอบเก่าปิดเป็น superseded พร้อมเหตุผล
- รอบใหม่ใช้ไฟล์แก้ และลิงก์ถึงกัน
- ไฟล์ทั้งสองไม่ถูกนับซ้ำ

## JSON

เทียบไฟล์ที่ดาวน์โหลดกับ `expected.json` โดยไม่ต้องเทียบ `source_meta`

## ปัญหาที่รู้แล้ว

ตอนนี้ระบบยังไม่เป็นตามผลที่ควรได้: รอบแรกผ่านเองแล้วเตือนราคาที่ขั้นข้อมูล ไม่ได้ให้คนตรวจที่ขั้น mapping ส่วนการแทนไฟล์ทำงานถูก
