# P07 CSV ภาษาไทยแบบ TIS-620

**สถานการณ์:** ERP ไทยรุ่นเก่า export เป็น Windows-874

**ลูกค้า:** `MTP07`

**ไฟล์:**
- `สินค้า.csv`

## วิธีทำ

สร้างลูกค้าตามรหัสของเคส (เช่น `MTP01`) แล้วอัปโหลดเหมือนกลุ่ม L

## ผลที่ควรได้

- ภาษาไทยอ่านถูกทุกแถว ไม่มีตัวอักษรเพี้ยน
- ได้ 12 รายการ และ JSON ตรงกับ expected.json

ค่าที่ควรเห็นในระบบ:

- สถานะรอบ: `review`
- จำนวนรายการ: `12`
- รายการผิดสัญญา JSON: `0`

## JSON

เทียบไฟล์ที่ดาวน์โหลดกับ `expected.json` โดยไม่ต้องเทียบ `source_meta`
