# A09 CSV ที่เครื่องหมายคำพูดไม่ปิด

**สถานการณ์:** ชื่อสินค้ามีเครื่องหมาย " แล้ว ERP ไม่ escape ทำให้ข้อมูลหลังจากนั้นถูกรวมเป็นช่องเดียว

**ลูกค้า:** `MTFILE`

**ไฟล์:**
- `export.csv`

## วิธีทำ

สร้างลูกค้า `MTFILE` ครั้งเดียว แล้วใช้กับทุกเคสในกลุ่มนี้ ไปที่ อัปโหลดไฟล์ > รวมไฟล์ของลูกค้า เลือก `MTFILE` แล้วอัปโหลดไฟล์ของเคส

## ผลที่ควรได้

- รอบล้มเหลวอย่างชัดเจน ไม่ใช่ได้ข้อมูลครึ่งเดียว
- ไม่มี JSON ออกมา

ค่าที่ควรเห็นในระบบ:

- ตอนอัปโหลด: `accepted`
- สถานะรอบ: `failed`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา
