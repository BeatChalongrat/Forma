# B01 อัปโหลดหลายไฟล์พร้อมกัน ปนทั้งไฟล์ดีและไฟล์เสีย

**สถานการณ์:** คืนเดียวได้ไฟล์หลายแบบ

**ต้องทำก่อน:** `R00`

**ไฟล์:**
- `1_MTEXP_รอบใหม่.xlsx`
- `2_ไม่รู้จัก.xlsx`
- `3_ไฟล์เสีย.xlsx`
- `4_ซ้ำ/1_MTEXP_รอบใหม่.xlsx`

## วิธีทำ

เลือกไฟล์ 1, 2, 3 และไฟล์ในโฟลเดอร์ 4_ซ้ำ แล้วลากทั้งหมดไปหน้า อัปโหลดไฟล์ พร้อมกัน

## ผลที่ควรได้

- 1_MTEXP ผ่านเองจนได้ JSON
- 2_ไม่รู้จัก รอให้เลือกลูกค้า
- 3_ไฟล์เสีย ล้มเหลวและบอกเหตุผล ไม่ทำให้ไฟล์อื่นหยุด
- 4_ไฟล์เดิมซ้ำ ถูกข้าม

ค่าที่ควรเห็นในระบบ:

- ไฟล์ที่ถูกข้าม: `1`
- `1_MTEXP_รอบใหม่.xlsx`: `ready`
- `2_ไม่รู้จัก.xlsx`: `needs_customer`
- `3_ไฟล์เสีย.xlsx`: `failed`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา
