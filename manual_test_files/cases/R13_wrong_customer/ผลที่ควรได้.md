# R13 ไฟล์ของลูกค้าอื่น (MTOTHER) ถูกอัปให้ MTEXP

**สถานการณ์:** รูปแบบไฟล์เหมือน Express เป๊ะ แต่เป็นสินค้าของอีกราย

**ลูกค้า:** `MTEXP`
**ต้องทำก่อน:** `R00`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`
- `ไฟล์ตั้งต้น_MTOTHER.xlsx`

## วิธีทำ

ก่อนทำเคสนี้ อัปโหลด ไฟล์ตั้งต้น_MTOTHER.xlsx ให้ลูกค้า MTOTHER แล้วอนุมัติจนส่งออกได้ จากนั้นอัปโหลด สินค้า_MTEXP_ต.ค.69.xlsx ให้ลูกค้า MTEXP

## ผลที่ควรได้

- ระบบต้องไม่รวมข้อมูลเข้าลูกค้าผิดราย
- บอกว่าน่าจะเป็นไฟล์ของ MTOTHER
- กดย้ายไปลูกค้าที่ถูกได้

ค่าที่ควรเห็นในระบบ:

- ข้อสรุป: `wrong_customer`
- สิ่งที่ระบบให้ทำ: `assign_customer`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา

## ปัญหาที่รู้แล้ว

ตอนนี้ระบบยังไม่เป็นตามผลที่ควรได้: ได้ other_customer_unconfirmed แทน wrong_customer เพราะรหัสสินค้าของสองรายไม่ซ้อนกันจึงเทียบค่าไม่ได้ ผลที่ให้ทำยังเป็นย้ายลูกค้าเหมือนกัน
