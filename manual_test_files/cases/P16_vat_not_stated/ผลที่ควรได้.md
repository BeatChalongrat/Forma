# P16 ไม่ได้บอกว่าราคารวม VAT หรือไม่

**สถานการณ์:** หัวคอลัมน์เขียนแค่ 'ราคาขาย'

**ลูกค้า:** `MTP16`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

สร้างลูกค้าตามรหัสของเคส (เช่น `MTP01`) แล้วอัปโหลดเหมือนกลุ่ม L

## ผลที่ควรได้

- ระบบต้องถามว่าราคารวม VAT หรือไม่ ห้ามเดาเงียบ ๆ
- คำถามอยู่ในหน้าตรวจ

ค่าที่ควรเห็นในระบบ:

- สถานะรอบ: `review`
- ต้องมีคำถามเรื่อง: `price.vat_included`
- จำนวนรายการ: `12`
