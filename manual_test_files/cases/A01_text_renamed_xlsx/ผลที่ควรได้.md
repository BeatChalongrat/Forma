# A01 ไฟล์ข้อความที่เปลี่ยนนามสกุลเป็น .xlsx

**สถานการณ์:** ลูกค้าเปลี่ยนชื่อไฟล์ report.txt เป็น .xlsx เอง

**ลูกค้า:** `MTFILE`

**ไฟล์:**
- `สินค้า.xlsx`

## วิธีทำ

สร้างลูกค้า `MTFILE` ครั้งเดียว แล้วใช้กับทุกเคสในกลุ่มนี้ ไปที่ อัปโหลดไฟล์ > รวมไฟล์ของลูกค้า เลือก `MTFILE` แล้วอัปโหลดไฟล์ของเคส

## ผลที่ควรได้

- ถูกปฏิเสธตอนอัปโหลด พร้อมบอกว่าเนื้อไฟล์ไม่ใช่ Excel
- ไม่มีรอบที่ค้างเงียบ ๆ และไม่มีข้อมูลว่างเปล่าเข้าระบบ

ค่าที่ควรเห็นในระบบ:

- ตอนอัปโหลด: `rejected`
- ข้อความต้องมีคำว่า: `content is not an Excel workbook`
