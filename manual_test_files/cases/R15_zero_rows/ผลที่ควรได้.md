# R15 โครงสร้างเดิม แต่ไม่มีข้อมูล

**สถานการณ์:** export ตอนฐานข้อมูลว่าง

**ลูกค้า:** `MTEXP`
**ต้องทำก่อน:** `R00`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

ทำ `R00` ให้จบก่อน จนดาวน์โหลด JSON ได้ จากนั้นอัปโหลดแต่ละเคสให้ลูกค้า `MTEXP` ทีละเคส ดูผลแล้วเปิดเมนูของรอบ เลือก ยกเลิกรอบ โดยไม่ต้องกดยอมรับ เว้นแต่เคสบอกให้ทำ รอบที่ยกเลิกจะไม่กระทบเคสถัดไป

## ผลที่ควรได้

- ระบบระงับ เพราะไม่มีข้อมูล
- ไม่แทนที่ข้อมูลรอบก่อน

ค่าที่ควรเห็นในระบบ:

- สถานะรอบ: `blocked`
- การตัดสินของ policy: `block`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา

## ปัญหาที่รู้แล้ว

ตอนนี้ระบบยังไม่เป็นตามผลที่ควรได้: รอบล้มเหลวด้วย 'profile contains no tables' แทนที่จะถูกระงับด้วยเหตุผลไม่มีข้อมูล
