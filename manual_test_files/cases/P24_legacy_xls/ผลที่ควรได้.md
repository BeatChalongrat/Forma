# P24 ไฟล์ Excel รุ่นเก่า .xls

**สถานการณ์:** ERP เก่ายัง export เป็น .xls

**ลูกค้า:** `MTP24`

**ไฟล์:**
- `สินค้า.xls`

## วิธีทำ

สร้างลูกค้าตามรหัสของเคส (เช่น `MTP01`) แล้วอัปโหลดเหมือนกลุ่ม L

## ผลที่ควรได้

- หน้าอัปโหลดรับไฟล์นี้
- อ่านได้ แต่ระบบต้องให้คนตรวจทุกรอบ เพราะตรวจสูตรและรูปแบบไม่ได้ละเอียดเท่า .xlsx
- ได้ 12 รายการ

ค่าที่ควรเห็นในระบบ:

- สถานะรอบ: `review`
- จำนวนรายการ: `12`
- รายการผิดสัญญา JSON: `0`

## JSON

เทียบไฟล์ที่ดาวน์โหลดกับ `expected.json` โดยไม่ต้องเทียบ `source_meta`
