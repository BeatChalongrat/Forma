# A08 ไฟล์ Excel ที่ใส่รหัสผ่าน

**สถานการณ์:** ลูกค้าตั้งรหัสผ่านก่อนส่ง (รหัสคือ forma1234)

**ลูกค้า:** `MTFILE`

**ไฟล์:**
- `สินค้า_ใส่รหัสผ่าน.xlsx`

## วิธีทำ

สร้างลูกค้า `MTFILE` ครั้งเดียว แล้วใช้กับทุกเคสในกลุ่มนี้ ไปที่ อัปโหลดไฟล์ > รวมไฟล์ของลูกค้า เลือก `MTFILE` แล้วอัปโหลดไฟล์ของเคส

## ผลที่ควรได้

- รอบล้มเหลวอย่างชัดเจน และบอกว่าอาจมีการเข้ารหัส
- ไม่มี JSON ออกมา

ค่าที่ควรเห็นในระบบ:

- ตอนอัปโหลด: `accepted`
- สถานะรอบ: `failed`
- ข้อความต้องมีคำว่า: `encryption`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา
