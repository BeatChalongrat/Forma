**ไฟล์:**

## วิธีทำ

สร้างลูกค้าตามรหัสของเคส (เช่น `MTQ01`) แล้วอัปโหลดเหมือนกลุ่ม L ดูว่าระบบเตือนตรงตามเคสหรือไม่

## ผลที่ควรได้

- รายการที่ไม่มีราคาผิดสัญญา JSON และต้องแก้ก่อนอนุมัติ
- ต้องไม่กลายเป็นราคา 0
- ส่งออก JSON ไม่ได้จนกว่าจะแก้

ค่าที่ควรเห็นในระบบ:

- สถานะรอบ: `review`
- รายการผิดสัญญา JSON: `4`
- ข้อสรุปขั้นข้อมูล: `contract_broken`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา
