# R14 ไฟล์คนละเรื่อง (ใบแจ้งหนี้)

**สถานการณ์:** ลูกค้าแนบไฟล์ผิด

**ลูกค้า:** `MTEXP`
**ต้องทำก่อน:** `R00`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

ทำ `R00` ให้จบก่อน จนดาวน์โหลด JSON ได้ จากนั้นอัปโหลดแต่ละเคสให้ลูกค้า `MTEXP` ทีละเคส ดูผลแล้วเปิดเมนูของรอบ เลือก ยกเลิกรอบ โดยไม่ต้องกดยอมรับ เว้นแต่เคสบอกให้ทำ รอบที่ยกเลิกจะไม่กระทบเคสถัดไป

## ผลที่ควรได้

- ระบบระงับทันที เพราะไม่ใช่รูปแบบที่อนุมัติไว้
- แก้ด้วยการแก้ mapping ไม่ได้ ต้องปฏิเสธหรือยกเลิก

ค่าที่ควรเห็นในระบบ:

- สถานะรอบ: `blocked`
- การตัดสินของ policy: `block`
- ข้อสรุป: `blocked_unrelated`
- ชนิดการเปลี่ยนรูปแบบ: `unrelated_file`
