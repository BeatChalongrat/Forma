# R18 ราคาขึ้นเกิน 30% บางรายการ

**สถานการณ์:** คีย์ผิด หรือขึ้นราคาจริง

**ลูกค้า:** `MTEXP`
**ต้องทำก่อน:** `R00`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

ทำ `R00` ให้จบก่อน จนดาวน์โหลด JSON ได้ จากนั้นอัปโหลดแต่ละเคสให้ลูกค้า `MTEXP` ทีละเคส ดูผลแล้วเปิดเมนูของรอบ เลือก ยกเลิกรอบ โดยไม่ต้องกดยอมรับ เว้นแต่เคสบอกให้ทำ รอบที่ยกเลิกจะไม่กระทบเคสถัดไป

## ผลที่ควรได้

- โครงสร้างผ่าน แต่ขั้นข้อมูลต้องเตือนราคาที่กระโดด
- ต้องให้คนรับทราบก่อนอนุมัติ

ค่าที่ควรเห็นในระบบ:

- ข้อสรุปขั้นข้อมูล: `price_move`
- ต้องมีคำเตือนเรื่อง: `price`
