# S01 ใช้รูปแบบ JSON ของตัวเอง

**สถานการณ์:** ลงทะเบียน JSON ปลายทางแบบใหม่ แล้วแปลงไฟล์เดิมให้ออกมาตามรูปแบบนั้น

**ลูกค้า:** `MTS01`

**ไฟล์:**
- `shop_item.schema.json`
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

ไปที่ ตั้งค่า > Target formats แล้วเพิ่ม shop_item.schema.json จากนั้นแก้ลูกค้า MTS01 ที่ช่อง Target format for new imports ก่อนอัปโหลดไฟล์

## ผลที่ควรได้

- ลงทะเบียนรูปแบบผ่าน
- JSON มีแค่ 4 ฟิลด์ที่กำหนด ไม่มีฟิลด์เกิน
- ตรงกับ expected.json

ค่าที่ควรเห็นในระบบ:

- ตอนลงทะเบียน: `accepted`
- จำนวนรายการ: `12`

## JSON

เทียบไฟล์ที่ดาวน์โหลดกับ `expected.json` โดยไม่ต้องเทียบ `source_meta`
