**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

สร้างลูกค้าตามรหัสของเคส (เช่น `MTQ01`) แล้วอัปโหลดเหมือนกลุ่ม L ดูว่าระบบเตือนตรงตามเคสหรือไม่

## ผลที่ควรได้

- รายการที่ไม่มีชื่อผิดสัญญา JSON
- ต้องแก้ก่อนส่งออก

ค่าที่ควรเห็นในระบบ:

- สถานะรอบ: `review`
- รายการผิดสัญญา JSON: `2`
- ข้อสรุปขั้นข้อมูล: `contract_broken`
