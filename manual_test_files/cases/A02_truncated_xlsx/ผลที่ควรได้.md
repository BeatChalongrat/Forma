# A02 ไฟล์ Excel ที่ดาวน์โหลดมาไม่ครบ

**สถานการณ์:** ไฟล์แนบอีเมลขาดกลางทาง

**ลูกค้า:** `MTFILE`

**ไฟล์:**
- `สินค้า.xlsx`

## วิธีทำ

สร้างลูกค้า `MTFILE` ครั้งเดียว แล้วใช้กับทุกเคสในกลุ่มนี้ ไปที่ อัปโหลดไฟล์ > รวมไฟล์ของลูกค้า เลือก `MTFILE` แล้วอัปโหลดไฟล์ของเคส

## ผลที่ควรได้

- ถูกปฏิเสธตอนอัปโหลด และบอกว่าไม่ใช่ workbook ที่ถูกต้อง
- ไม่มีรอบที่ค้างเงียบ ๆ และไม่มีข้อมูลว่างเปล่าเข้าระบบ

ค่าที่ควรเห็นในระบบ:

- ตอนอัปโหลด: `rejected`
- ข้อความต้องมีคำว่า: `not a valid Excel workbook`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา
