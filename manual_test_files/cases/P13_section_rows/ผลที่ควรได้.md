# P13 รายงานแบ่งหมวดด้วยแถวคั่น

**สถานการณ์:** ERP พิมพ์ 'หมวด: เครื่องดื่ม' เป็นแถวคั่น และมีแถวรวมท้ายทุกหมวด

**ลูกค้า:** `MTP13`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

สร้างลูกค้าตามรหัสของเคส (เช่น `MTP01`) แล้วอัปโหลดเหมือนกลุ่ม L

## ผลที่ควรได้

- แถวคั่นและแถวรวมหมวดต้องไม่กลายเป็นสินค้า
- ถ้าทำไม่ได้ ต้องให้คนตรวจ ไม่ใช่ผ่านเงียบ ๆ

ค่าที่ควรเห็นในระบบ:

- สถานะรอบ: `review`
- จำนวนรายการ: `12`
- รายการผิดสัญญา JSON: `0`

## JSON

เทียบไฟล์ที่ดาวน์โหลดกับ `expected.json` โดยไม่ต้องเทียบ `source_meta`

## ปัญหาที่รู้แล้ว

ตอนนี้ระบบยังไม่เป็นตามผลที่ควรได้: แถวคั่นและแถวรวมหมวดกลายเป็น 5 รายการผิดสัญญา ระบบจับได้ แต่ต้องลบเอง
