# R10 คอลัมน์เดิม แต่ค่ากลายเป็นราคาทุน

**สถานการณ์:** หัวคอลัมน์เหมือนเดิม แต่ ERP เปลี่ยนไปใส่ราคาทุน

**ลูกค้า:** `MTEXP`
**ต้องทำก่อน:** `R00`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

ทำ `R00` ให้จบก่อน จนดาวน์โหลด JSON ได้ จากนั้นอัปโหลดแต่ละเคสให้ลูกค้า `MTEXP` ทีละเคส ดูผลแล้วเปิดเมนูของรอบ เลือก ยกเลิกรอบ โดยไม่ต้องกดยอมรับ เว้นแต่เคสบอกให้ทำ รอบที่ยกเลิกจะไม่กระทบเคสถัดไป

## ผลที่ควรได้

- โครงสร้างเหมือนเดิมแต่ค่าเป็น ×0.62 ของรอบก่อนทุกรายการ
- ระบบต้องจับได้จากข้อมูล ไม่ปล่อยผ่าน
- ถามว่าหน่วย แพ็ค หรือสกุลเงินเปลี่ยนหรือไม่

ค่าที่ควรเห็นในระบบ:

- การตัดสินของ policy: `review`
- ข้อสรุป: `scaled`
- สิ่งที่ระบบให้ทำ: `fix_mapping`
