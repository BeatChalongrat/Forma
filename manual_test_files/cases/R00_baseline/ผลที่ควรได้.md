# R00 ไฟล์ตั้งต้นของลูกค้า MTEXP

**สถานการณ์:** ทำเคสนี้ก่อนทุกเคสในกลุ่ม R: อนุมัติ mapping อนุมัติข้อมูล และส่งออก

**ลูกค้า:** `MTEXP`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

ทำ `R00` ให้จบก่อน จนดาวน์โหลด JSON ได้ จากนั้นอัปโหลดแต่ละเคสให้ลูกค้า `MTEXP` ทีละเคส ดูผลแล้วเปิดเมนูของรอบ เลือก ยกเลิกรอบ โดยไม่ต้องกดยอมรับ เว้นแต่เคสบอกให้ทำ รอบที่ยกเลิกจะไม่กระทบเคสถัดไป

## ผลที่ควรได้

- ลูกค้าใหม่ ระบบให้คนตรวจ
- เมื่ออนุมัติแล้ว JSON ตรงกับ expected.json
- รูปแบบนี้จะเป็นรูปแบบที่อนุมัติแล้วของลูกค้า MTEXP

ค่าที่ควรเห็นในระบบ:

- สถานะรอบ: `review`
- การตัดสินของ policy: `review`
- ข้อสรุป: `first_time`
- จำนวนรายการ: `12`
- รายการผิดสัญญา JSON: `0`

## JSON
