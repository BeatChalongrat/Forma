# R05 เปลี่ยนชื่อคอลัมน์ ค่าเหมือนเดิม

**สถานการณ์:** อัปเกรด ERP แล้วชื่อคอลัมน์เปลี่ยน

**ลูกค้า:** `MTEXP`
**ต้องทำก่อน:** `R00`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

ทำ `R00` ให้จบก่อน จนดาวน์โหลด JSON ได้ จากนั้นอัปโหลดแต่ละเคสให้ลูกค้า `MTEXP` ทีละเคส ดูผลแล้วเปิดเมนูของรอบ เลือก ยกเลิกรอบ โดยไม่ต้องกดยอมรับ เว้นแต่เคสบอกให้ทำ รอบที่ยกเลิกจะไม่กระทบเคสถัดไป

## ผลที่ควรได้

- ระบบเห็นว่าโครงสร้างเปลี่ยน แต่ค่าเหมือนเดิม
- กดยอมรับได้ในคลิกเดียว (rename_only)

ค่าที่ควรเห็นในระบบ:

- ชนิดการเปลี่ยนรูปแบบ: `columns_renamed`
- ข้อสรุป: `rename_only`
- สิ่งที่ระบบให้ทำ: `accept`
- จำนวนรายการ: `12`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา

## ปัญหาที่รู้แล้ว

ตอนนี้ระบบยังไม่เป็นตามผลที่ควรได้: เปลี่ยนชื่อคอลัมน์ภาษาไทยถูกรายงานเป็น columns_removed ไม่ใช่ columns_renamed (คำตัดสิน rename_only ยังถูก)
