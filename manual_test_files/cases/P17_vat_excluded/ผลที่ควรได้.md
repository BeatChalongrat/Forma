# P17 ราคาไม่รวม VAT

**สถานการณ์:** หัวคอลัมน์บอกชัดว่าไม่รวม VAT

**ลูกค้า:** `MTP17`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

สร้างลูกค้าตามรหัสของเคส (เช่น `MTP01`) แล้วอัปโหลดเหมือนกลุ่ม L

## ผลที่ควรได้

- vat_included เป็น false
- ตัวเลขราคาไม่ถูกบวก VAT เพิ่ม
- JSON ตรงกับ expected.json

ค่าที่ควรเห็นในระบบ:

- สถานะรอบ: `review`
- จำนวนรายการ: `12`
- รายการผิดสัญญา JSON: `0`

## JSON

เทียบไฟล์ที่ดาวน์โหลดกับ `expected.json` โดยไม่ต้องเทียบ `source_meta`
