# R04 มีคอลัมน์ใหม่เพิ่ม

**สถานการณ์:** ERP เพิ่มคอลัมน์ 'จุดสั่งซื้อ'

**ลูกค้า:** `MTEXP`
**ต้องทำก่อน:** `R00`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

ทำเคสนี้เป็นเคสสุดท้ายของกลุ่ม R เพราะ mapping ที่ผ่านเองจะกลายเป็นรูปแบบล่าสุดของลูกค้า แม้ยกเลิกรอบแล้วก็ตาม

## ผลที่ควรได้

- ระบบรู้ว่ามีคอลัมน์เพิ่มและไม่กระทบของเดิม
- ผ่านเอง ได้ข้อมูลครบ

ค่าที่ควรเห็นในระบบ:

- การตัดสินของ policy: `auto_approve`
- ชนิดการเปลี่ยนรูปแบบ: `columns_added`
- จำนวนรายการ: `12`
- รายการผิดสัญญา JSON: `0`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา
