# A03 ไฟล์ zip ที่ตั้งชื่อเป็น .xlsx

**สถานการณ์:** ลูกค้าส่งไฟล์บีบอัดมาโดยเปลี่ยนนามสกุล

**ลูกค้า:** `MTFILE`

**ไฟล์:**
- `สินค้า.xlsx`

## วิธีทำ

สร้างลูกค้า `MTFILE` ครั้งเดียว แล้วใช้กับทุกเคสในกลุ่มนี้ ไปที่ อัปโหลดไฟล์ > รวมไฟล์ของลูกค้า เลือก `MTFILE` แล้วอัปโหลดไฟล์ของเคส

## ผลที่ควรได้

- ถูกปฏิเสธ และบอกว่าเป็น zip ที่ไม่ใช่ Excel
- ไม่มีรอบที่ค้างเงียบ ๆ และไม่มีข้อมูลว่างเปล่าเข้าระบบ

ค่าที่ควรเห็นในระบบ:

- ตอนอัปโหลด: `rejected`
- ข้อความต้องมีคำว่า: `zip container is not an Excel workbook`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา
