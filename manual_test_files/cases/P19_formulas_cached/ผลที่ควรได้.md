# P19 ราคาเป็นสูตร Excel ที่บันทึกค่าไว้แล้ว

**สถานการณ์:** ราคา = ทุน × 1.07 และไฟล์เคยเปิดบันทึกใน Excel จึงมีค่าผลลัพธ์

**ลูกค้า:** `MTP19`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

สร้างลูกค้าตามรหัสของเคส (เช่น `MTP01`) แล้วอัปโหลดเหมือนกลุ่ม L

## ผลที่ควรได้

- อ่านค่าผลลัพธ์ได้ แต่ระบบต้องแจ้งว่าไฟล์มีสูตร และให้คนตรวจ
- ราคาตรงกับที่เห็นใน Excel

ค่าที่ควรเห็นในระบบ:

- สถานะรอบ: `review`
- จำนวนรายการ: `12`
- รายการผิดสัญญา JSON: `0`
