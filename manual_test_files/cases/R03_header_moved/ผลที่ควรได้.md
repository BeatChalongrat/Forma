# R03 หัวตารางเลื่อนลง 2 แถว

**สถานการณ์:** ERP เพิ่มแถวหัวรายงาน

**ลูกค้า:** `MTEXP`
**ต้องทำก่อน:** `R00`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

ทำ `R00` ให้จบก่อน จนดาวน์โหลด JSON ได้ จากนั้นอัปโหลดแต่ละเคสให้ลูกค้า `MTEXP` ทีละเคส ดูผลแล้วเปิดเมนูของรอบ เลือก ยกเลิกรอบ โดยไม่ต้องกดยอมรับ เว้นแต่เคสบอกให้ทำ รอบที่ยกเลิกจะไม่กระทบเคสถัดไป

## ผลที่ควรได้

- ระบบรู้ว่าแค่หัวตารางเลื่อน และผ่านเอง
- ได้ข้อมูลครบเหมือนเดิม

ค่าที่ควรเห็นในระบบ:

- การตัดสินของ policy: `auto_approve`
- ชนิดการเปลี่ยนรูปแบบ: `header_moved`
- จำนวนรายการ: `12`
- รายการผิดสัญญา JSON: `0`

## JSON

เทียบไฟล์ที่ดาวน์โหลดกับ `expected.json` โดยไม่ต้องเทียบ `source_meta`

## ปัญหาที่รู้แล้ว

ตอนนี้ระบบยังไม่เป็นตามผลที่ควรได้: หัวตารางเลื่อนถูกรายงานเป็น identical ไม่ใช่ header_moved (ข้อมูลยังถูก)
