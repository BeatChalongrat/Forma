# R17 สินค้าเปลี่ยนใหม่ทั้งหมด

**สถานการณ์:** รหัสทั้งชุดเปลี่ยน

**ลูกค้า:** `MTEXP`
**ต้องทำก่อน:** `R00`

**ไฟล์:**
- `สินค้า_MTEXP_ต.ค.69.xlsx`

## วิธีทำ

ทำ `R00` ให้จบก่อน จนดาวน์โหลด JSON ได้ จากนั้นอัปโหลดแต่ละเคสให้ลูกค้า `MTEXP` ทีละเคส ดูผลแล้วเปิดเมนูของรอบ เลือก ยกเลิกรอบ โดยไม่ต้องกดยอมรับ เว้นแต่เคสบอกให้ทำ รอบที่ยกเลิกจะไม่กระทบเคสถัดไป

## ผลที่ควรได้

- ระบบเตือนว่ารายการสินค้าถูกแทนที่ทั้งหมด
- ต้องให้คนยืนยันก่อน

ค่าที่ควรเห็นในระบบ:

- ข้อสรุปขั้นข้อมูล: `catalogue_replaced`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา

## ปัญหาที่รู้แล้ว

ตอนนี้ระบบยังไม่เป็นตามผลที่ควรได้: ถูกระงับโดย sandbox (รายการซ้ำเพิ่ม 4) ก่อนถึงขั้นข้อมูล จึงไม่เห็น catalogue_replaced
