# A07 ไฟล์ PDF ตรง ๆ

**สถานการณ์:** ลูกค้าส่งใบรายการเป็น PDF

**ลูกค้า:** `MTFILE`

**ไฟล์:**
- `ราคาสินค้า.pdf`

## วิธีทำ

สร้างลูกค้า `MTFILE` ครั้งเดียว แล้วใช้กับทุกเคสในกลุ่มนี้ ไปที่ อัปโหลดไฟล์ > รวมไฟล์ของลูกค้า เลือก `MTFILE` แล้วอัปโหลดไฟล์ของเคส

## ผลที่ควรได้

- หน้าเว็บบอกทันทีว่าอ่านไฟล์นี้ไม่ได้ และไม่เพิ่มไฟล์เข้ารายการ
- ไม่มีรอบที่ค้างเงียบ ๆ และไม่มีข้อมูลว่างเปล่าเข้าระบบ

ค่าที่ควรเห็นในระบบ:

- ตอนอัปโหลด: `rejected`
- ข้อความต้องมีคำว่า: `Unsupported file type`
