# A05 ไฟล์ PDF ที่ตั้งชื่อเป็น .csv

**สถานการณ์:** เปลี่ยนนามสกุลผิด

**ลูกค้า:** `MTFILE`

**ไฟล์:**
- `export.csv`

## วิธีทำ

สร้างลูกค้า `MTFILE` ครั้งเดียว แล้วใช้กับทุกเคสในกลุ่มนี้ ไปที่ อัปโหลดไฟล์ > รวมไฟล์ของลูกค้า เลือก `MTFILE` แล้วอัปโหลดไฟล์ของเคส

## ผลที่ควรได้

- ถูกปฏิเสธ ไม่กลายเป็นตัวอักษรเพี้ยนในระบบ
- ไม่มีรอบที่ค้างเงียบ ๆ และไม่มีข้อมูลว่างเปล่าเข้าระบบ

ค่าที่ควรเห็นในระบบ:

- ตอนอัปโหลด: `rejected`
- ข้อความต้องมีคำว่า: `binary content in a text file`

## JSON

เคสนี้ไม่ควรมี JSON ที่ถูกต้องออกมาจนกว่าจะแก้ปัญหา
