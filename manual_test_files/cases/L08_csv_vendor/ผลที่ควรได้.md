# L08 CSV หลายไฟล์ หลาย encoding

**สถานการณ์:** สินค้า สต็อก และโปรโมชั่นแยกไฟล์ และ encoding ไม่เหมือนกัน

**ลูกค้า:** `MTL08`

**ไฟล์:**
- `products_20261001.csv`
- `stock_20261001.csv`
- `promotions_20261001.csv`

## วิธีทำ

สร้างลูกค้าตามรหัสของเคส (เช่น `MTL01`) ไปที่ อัปโหลดไฟล์ > รวมไฟล์ของลูกค้า แล้วอัปโหลดทุกไฟล์ในโฟลเดอร์ ยกเว้น `expected.json` และ `ผลที่ควรได้.md` จากนั้นตรวจ อนุมัติ และดาวน์โหลด JSON มาเทียบ

## ผลที่ควรได้

- ระบบถามว่าไฟล์แรกของลูกค้ารายนี้ถูกต้องไหม (ลูกค้าใหม่ต้องให้คนดูทุกครั้ง)
- จับคู่คอลัมน์ได้ครบ และได้ 12 รายการ
- เมื่ออนุมัติแล้ว JSON ตรงกับ expected.json

ค่าที่ควรเห็นในระบบ:

- สถานะรอบ: `review`
- การตัดสินของ policy: `review`
- จำนวนรายการ: `12`
- รายการผิดสัญญา JSON: `0`

## JSON

เทียบไฟล์ที่ดาวน์โหลดกับ `expected.json` โดยไม่ต้องเทียบ `source_meta`
